# ステルス退勤支援システム「THE GHOST」👻💼

> **「定時に帰ることは、罪ではない。生存戦略だ。」**

現代のオフィスに潜む最大の脅威――上司の「あ、〇〇君、今ちょっといい？」という死の宣告（通称：ラストミニッツ・タスク）。
『THE GHOST』は、高度なWeb技術を駆使してユーザーの存在感を極限まで希釈し、誰にも悟られずにオフィスから華麗に脱出（定時退勤）するためのステルス迷彩Webアプリケーションです。

---

## 🌟 主要機能

### 1. 擬似多忙画面偽装（ブラフ・スクリーン）🖥️
- **ハッカーターミナル**: 意味のない緑の文字列が超高速スクロールし、超絶激務を演出。
- **極彩色Excel**: 複雑怪奇な関数と無駄なグラフ10枚で近寄りがたいオーラを放射。
- **深刻なエラー画面**: 「致命的な例外が発生しました」と赤文字点滅。話しかけたら巻き込まれる空気を醸成。
- **パニックボタン**: マウスを高速で振るだけで、YouTube等の画面から0.05秒で日経平均株価チャートへ緊急切替。

### 2. 退路策定アルゴリズム（エスケープ・ルート・ナビ）🏃💨
- 周囲の音声・環境を擬似モニタリングし、上司のステータス（電話中／雑談中／トイレ離席）を解析。
- 上司離席の瞬間に画面が赤く点滅――**『チャンスタイム突入：残り猶予3分』**を発令。

### 3. 言い訳ジェネレーター（LLM連携）🤖
- 捕獲された瞬間に放つ、角が立たない緊急離脱カードを自動生成。
  - *Lv.1:* 「実家のルンバが脱走したと連絡がありまして」
  - *Lv.3:* 「本日18:30より、地域の乾電池分別ボランティアの長を務めておりまして」
  - *Lv.5:* 「これ以上オフィスにいると、私の持つスタンド能力が暴走してサーバーが落ちます」

### 4. 物理デコイ（身代わり）支援機能 🧥☕
- 席を離れる前の絶対防衛チェックリスト：
  - [x] 椅子の背もたれに「置きジャケット」を装着したか？
  - [x] デスク上に「温かい缶コーヒー」を配置したか？
  - [x] PC画面をあえて作業中ロックのまま放置したか？

### 5. アリバイ偽装Slack自動送信（ポスト・エスケープ）💬
- 脱出から30分後、社内チャットへ予約メッセージを射出：
  > 「電車の電波が悪く返信遅れます。急ぎの案件は明朝対応します！」

## ⚙️ 動作要件・スペック
- **脱出決定からPC即落ちまで:** 0.8秒以内（シャットダウン音無音化）
- **ピークタイム耐性:** 毎週金曜日 17:59〜18:05（週末の死を阻止する絶対防衛ライン）
- **プロセス偽装:** タスクマネージャー上は `Windows_Security_Update_Host.exe` として振る舞います。
